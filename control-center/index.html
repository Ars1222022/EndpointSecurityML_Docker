Kom igång stegvis
Varje steg kan köras separat

        
01
Starta API och databas
Grundsteget startar prediktions-API och PostgreSQL. API-dokumentationen visar tillgängliga anrop.

        
02
Ladda exempeldata i PostgreSQL
Importerar CSV:n till tabellen endpoint_activities. Importen gör inget om tabellen redan innehåller data.

        
03
Träna och jämför modeller
Random Forest tränas från PostgreSQL. DVC versionerar data/modellfiler och MLflow sparar Accuracy, Precision, Recall och F1.

        
04
Gör en prediktion
Öppna API-dokumentationen, välj POST /predict och skicka ProcessName och NetworkConnections.
Öppna Swagger

        
05
Automatisera med Airflow
Starta Airflow och kör DAG:en endpointsecurity_train_model. Airflow-resultaten syns också i MLflow.

        
06
Övervaka tjänsterna
Prometheus samlar API-mätvärden. Grafana öppnar den provisionerade API-dashboarden.

      

      
GitHub Actions · Docker Hub
Skapa först ett tomt GitHub-repository. Lägg innehållet i mappen EndpointSecurityML_Docker direkt i repositoryts rot; där ska du se compose.yaml och .github/workflows. Skriv sedan repository som ägare/repo här.
Publiceringsflödet behöver secrets med namnen DOCKER_USERNAME och DOCKER_PASSWORD. Spara dem manuellt via GitHub Settings om du inte vill använda formuläret.

        

        
För formuläret: installera GitHub CLI och kör gh auth login i terminalen först. Docker Hub-token skickas till gh, visas inte igen och sparas inte i webbläsaren. Klistra aldrig in en GitHub PAT här. GitHub skapar sin egen GITHUB_TOKEN automatiskt.
